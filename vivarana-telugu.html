1. సాధ్యమా? కాదా?

✅ సాధ్యమే (POSSIBLE)

మీ Fluke 378 FC మీటర్ చూపించే reading (ఉదా: -6.60 A dc) ని, Fluke వాళ్ళ app లేకుండా, మీ ఫోన్‌లో మీరు తయారు చేసుకున్న ఒక page లో live గా చూడవచ్చు. దానికి internet అవసరం లేదు.

నేను ఆ page ని ఇప్పటికే తయారు చేశాను: index.html (ఈ folder లోనే ఉంది). మీరు చేయాల్సింది దాన్ని మీ ఫోన్‌లో పెట్టుకోవడం మాత్రమే.

2. ఇది ఎలా పనిచేస్తుంది? (ఒక బొమ్మలో)

గమనించండి: ఈ బొమ్మలో ఎక్కడా internet / WiFi / SIM లేదు. మీటర్ → ఫోన్ నేరుగా radio ద్వారా. అందుకే offline పనిచేస్తుంది.

5. "HTTPS" అనేది ఏమిటి? ఎందుకు కావాలి? (అందరూ confuse అయ్యే point)

Chrome కి ఒక నియమం ఉంది:

"Bluetooth లాంటి hardware ని నేను నమ్మకమైన address నుంచి వచ్చిన page కి మాత్రమే ఇస్తాను."
  • నమ్మకమైన address = https:// తో మొదలయ్యే link (s = secure).
  • అందుకే మన index.html ని ఒక్కసారి internet లో ఒక https:// address వద్ద పెట్టాలి. దీన్నే "hosting" అంటారు.
  • ఇది free గా, 2 నిమిషాల్లో అవుతుంది (Netlify Drop అనే website లో file ని drag & drop చేస్తే చాలు).
  • ఒక్కసారి ఫోన్ Chrome లో ఆ link open చేస్తే, page తనను తాను ఫోన్‌లో save చేసుకుంటుంది. ఆ తర్వాత internet లేకున్నా open అవుతుంది.
❌ http:// (s లేకుండా)
Chrome Bluetooth ఇవ్వదు
✅ https://
Chrome Bluetooth ఇస్తుంది

6. ఒక్కసారి చేయాల్సిన Setup (సుమారు 10 నిమిషాలు)

5 files download చేయండిఈ folder లో: index.html, sw.js, manifest.json, icon-192.png, icon-512.png — అన్నీ ఒకే folder లో ఉంచండి. (index.html ఒక్కటే ముఖ్యం; మిగతావి "Install app" & offline కోసం.)
Laptop లో app.netlify.com/drop open చేయండిFree account create చేయండి (email చాలు). తర్వాత మీ fluke-dashboard folder ని ఆ page మీద drag & drop చేయండి. 30 సెకన్లలో ఒక link వస్తుంది: https://ఏదో-పేరు.netlify.app
ఆ link ని ఫోన్ Chrome లో open చేయండిPage పైన కుడివైపు "✔ offline ready" అని కనిపిస్తుంది = page ఫోన్‌లో save అయింది.
Home screen కి add చేయండిChrome menu (⋮) → "Add to Home screen" / "Install app". Home screen లో "Fluke Dash" icon వస్తుంది. ఇకపై internet అవసరం లేదు.
Permissionsఫోన్ Bluetooth ON. Android అడిగితే Location / Nearby devices → Allow. (Android Bluetooth scan కి Location అడుగుతుంది — ఇది Android నియమం.)
Demo mode తో testFluke Dash open → ▶ Demo mode నొక్కండి. మీటర్ లేకుండానే నకిలీ readings తో page ఎలా పనిచేస్తుందో చూడవచ్చు. ఇది practice కి.

7. రోజూ వాడకం — మీటర్ connect చేయడం

  • Wire ని clamp లో పెట్టి mode మార్చినా, page automatic గా update అవుతుంది.
  • పని అయ్యాక ⬇ Export CSV నొక్కితే అన్ని readings ఒక file గా download అవుతాయి → Excel లో open / WhatsApp లో share చేయవచ్చు.
  • Connection మధ్యలో పోతే page 5 సార్లు తనంతట తానే మళ్ళీ connect అవ్వడానికి try చేస్తుంది.
  • అయ్యాక Disconnect నొక్కండి లేదా మీటర్ OFF చేయండి.

9. ఒక్క విషయం మాత్రం మొదటిసారి test చేయాలి

మీటర్ లోపల reading ఉండే "పెట్టె" కి ఒక పొడవైన address ఉంటుంది (దీన్ని UUID అంటారు). ఇప్పటివరకు ఇది Fluke 376 FC మీద మాత్రమే బయట వాళ్ళు కనుగొని publish చేశారు:

b6981800-7562-11e2-b50d-00163e46f8fe → b6982901-7562-11e2-b50d-00163e46f8fe

మీ 378 FC అదే family కాబట్టి అదే address అయ్యే అవకాశం చాలా ఎక్కువ. మన page లో ఇవే default గా పెట్టాను.

✅ Connect చేయగానే అంకె వస్తే
→ అంతే, ఇక ఏమీ చేయనవసరం లేదు.
❌ Connected అయ్యి కూడా అంకె రాకపోతే
→ కింద 5 నిమిషాల fix.

Fix (అవసరమైతే మాత్రమే): nRF Connect app

  1. Play Store → "nRF Connect for Mobile" (free) install.
  2. మీటర్ F బటన్ → nRF Connect లో SCAN → 378FC → CONNECT.
  3. "Unknown Service" అని ఒకటి కనిపిస్తుంది → దాని UUID, దాని లోపల "Unknown Characteristic" (NOTIFY, READ) UUID note చేయండి.
  4. nRF Connect లో DISCONNECT చేయండి.
  5. మన page → Advanced → ఆ రెండు UUIDs paste → Connect meter.

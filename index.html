Capture settings

Reading below the zero threshold is marked red + "ZERO READING DETECTED" in Remarks.
Lead pot phase check: used only while Lead pot has no reference values — when all three phases R, Y, B are captured, a phase more than the limit (default 6 A) below the highest phase is an ERROR (orange ⚠ cell, "PHASE IMBALANCE ERROR" in Remarks). With reference values (card below) each phase is judged against its own reference ± tolerance instead — no error pop-up.
AUTO mode: when the live value rises above the zero threshold (clamp on), the app tracks the highest value for 4 seconds, saves it by itself (beep + vibration), moves to the next point and waits until the value falls back to ~0 before it can capture again. A 0 A point cannot be detected automatically (a dead heater looks like no clamp) — press Confirm for it. The Confirm button and ✎ Manual keep working in both modes. Values are always shown without the minus sign.

Features (Phase 2)

Switch a feature OFF and it disappears from every page (nothing is deleted). All ON by default.

Reference values (A)▸ tap to open

One reference per phase, same for every line. A captured value outside reference ± tolerance is an alarm: red ▲/▼ cell, one short toast + vibration at capture, "OUT OF RANGE" in Remarks, PDF, Google Sheet and Insights chat. Blank = no check for that phase. Zero readings stay a separate red alarm.

Copy from a line takes the readings of any line on this board as the new references (a known-good line). Default set = Lead pot 25.5 / 26.5 / 16.2 · Lift pipe 11 / 11 · Right pipe 11 / 11 · Cross block 6.0 · Elbow 5.6 · Tinboth-1 9 / 9 · Tinboth-2 9 / 9. When Lead pot has references, its old phase-imbalance rule is off (the references already cover it).

Operators & PINs▸ tap to open

One per line: Name | PIN (4–6 digits). With a list, the Entry page shows a name list + Sign in (PIN) instead of a free text box, so every reading carries a verified operator name. PINs are stored only as hashes (shown as ****). Empty list = free text as before.

How to use

  1. Setup → Connect meter (meter F button → Bluetooth symbol).
  2. Entry → Operator, Date, Shift → tap a Line. Each Date + Shift is its own board — changing them opens that board (a new one starts empty).
  3. Clamp on the shown point (e.g. Lead pot R). When the value is steady press ✔ Confirm. Next point comes automatically.
  4. AUTO switch (bottom, next to Confirm): turn it ON, clamp on and hold still 4 s — the highest value is saved by itself (beep + vibration) and the next point appears. Unclamp, clamp the next point → again. 0 A points → press Confirm.
  5. Reference alarm: the target card shows the reference for each point (e.g. Ref 25.5 A ± 5). A captured value outside reference ± tolerance turns the cell red with ▲ (high) / ▼ (low), one short toast + vibration — check that heater and re-capture. Remarks / PDF / Sheet show "OUT OF RANGE". Admin sets references in Setup → Reference values.
  6. No meter value? ✎ Manual lets anyone type a value — it is always marked as manual (✎ / italic* / "MANUAL").
  7. Need another point → ▲ Up / ▼ Down, R/Y/B, or tap a table cell. When a line is complete the app moves to the next line automatically; you can also tap any Line button.
  8. Board → Share report (PDF) → Save as PDF → WhatsApp. Copy summary = short text for a chat message. Period report = week / month PDF from the boards on this phone.
  9. NA / Skip when a point cannot be measured (line down, heater removed …) — saved as NA with the reason. History (or tap a Board value) = past values of that point with a trend line.
  10. Issues tab = every zero / error / range / NA of the open board: go to the point, mark Resolved with a note, attach a photo. Setup → Features switches any Phase 2 feature off.
  11. Signatures (Board, bottom card): when the readings are done the Operator signs with a finger, then the Supervisor, then the In-charge — in that order. The three signatures print at the bottom of the PDF report. A signed board is frozen: changing a reading asks to remove the signatures first.
  12. Insights chat — tap the round chat bubble (bottom-right of any page) for the full-screen chat, or scroll to the card on the Board. A red number on the bubble = new abnormal readings. ⋮ menu: hide bubble / badge / share whole chat / clear. The bot posts a remark when the board has an abnormal reading; tap Abnormal now?, Repeated problems, Trends, Vs previous board, What is pending? or type "line 3" / "H-2 R". Every answer has Copy and WhatsApp. Rule-based, works offline, never pops up.
